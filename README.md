🤖 Rule-Based Chatbot

A simple and interactive Rule-Based Chatbot built using HTML, CSS, and JavaScript. The chatbot responds to user messages by matching predefined keywords and provides dynamic replies such as greetings, jokes, current date, current time, and helpful responses. It also includes a typing indicator, quick reply buttons, and a modern chat interface for an engaging user experience.

⚙️ How It Works
The user types a message in the chat input.
JavaScript checks the message against predefined keyword rules.
If a keyword matches, the chatbot returns an appropriate response.
Dynamic responses are generated for the current date and time.
A typing indicator simulates the bot thinking before replying.
If no keyword matches, a fallback response is displayed.
Quick reply buttons help users start conversations easily.
